  application ID `com.jackh0006.bnbwallet`, vault magic/filenames, backup
  formats, device-secret identifiers, and existing environment variables remain
  unchanged.

  `Provides/Replaces/Conflicts: bnb-wallet`; `/usr/bin/bnb-wallet` remains as a
